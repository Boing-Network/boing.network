## Quick path (users)

1. Install [Boing Express](https://boing.express)
2. Request funds at [boing.network/faucet](https://boing.network/faucet)
3. Explore on [boing.observer](https://boing.observer)
4. Try apps on [boing.finance](https://boing.finance)
5. Optionally register / quest via the [Testnet portal](https://boing.network/testnet)

## Developers

1. Point RPC at `https://testnet-rpc.boing.network/`
2. Install `@boing-network/boing-sdk@^0.5.39`
3. Read [JSON-RPC](/developers/rpc/) and [SDK](/developers/sdk/)
4. Use Express for signing; never paste private keys into websites
5. Portal: [testnet developers hub](https://boing.network/testnet/developers)
