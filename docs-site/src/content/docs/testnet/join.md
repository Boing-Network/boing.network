title: Join testnet
description: The short path onto the Boing public testnet (chain 6913) for users, developers, and node operators.
---

The public testnet is chain **6913**. Pick the path that fits you.

## Users

1. Install [Boing Express](https://boing.express).
2. Get testnet BOING from the [faucet](https://boing.network/faucet).
3. Explore on [Boing Observer](https://boing.observer).
4. Try apps on [Boing Finance](https://boing.finance).
5. Optionally, register and follow quests on the [testnet portal](https://boing.network/testnet).

Step-by-step version: [Get started](/start/get-started/).

## Developers

1. Point your app at `https://testnet-rpc.boing.network/`.
2. Install `@boing-network/boing-sdk@^0.5.41`.
3. Read [JSON-RPC](/developers/rpc/), [SDK](/developers/sdk/), and [Wallet & dApps](/developers/wallet-dapps/).
4. Let users sign with Boing Express. Never ask for private keys on a website.
5. More tools: [testnet developer hub](https://boing.network/testnet/developers).

## Node operators

1. [Run a full node](/nodes/run-a-node/) with the four testnet consensus settings and the
   [official bootnode](/nodes/bootnodes/) `/ip4/169.155.48.188/tcp/4001`.
2. Once it is in sync, [become a validator](/nodes/validator/) with a 100 BOING bond.
3. If something goes wrong, check [Troubleshooting](/nodes/troubleshooting/).

## Incentives

Running a testnet node or using testnet apps is not incentivized right now, and **testnet participation is not a
claim on mainnet tokens**. Plans for an incentivized testnet are in the tokenomics papers in the
[PDF library](/resources/pdfs/).
